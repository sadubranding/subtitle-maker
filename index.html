Subtitle Maker

MP3 upload করুন → Speech to Text → Subtitle edit → Export। Bangla + English. সব কাজ আপনার browser-এই হয়, কোনো server লাগে না।

1. Audio & Speech to Text

প্রথমবার model download হবে (Small ≈ 250MB), এরপর browser-এ cache থাকবে। Audio কোথাও upload হয় না।

2. Edit subtitles

Settings বদলালে subtitle নতুন করে ভাগ হবে (হাতে করা edit মুছে যাবে)। নিচে প্রতিটা cue নিজে edit করা যাবে।

3. Export

PDF-এর জন্য print window খুলবে, সেখানে "Save as PDF" বেছে নিন (এতে বাংলা অক্ষর ঠিক থাকে)।

GitHub sync (progress সব device-এ পেতে)

Token শুধু এই browser-এর localStorage-এ থাকে। Public repo-তে progress file দেখা যাবে, তাই private repo ব্যবহার করুন।
